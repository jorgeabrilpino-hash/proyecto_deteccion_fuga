# Fases del proyecto, v1

## Fase 1, base actual
Objetivo: validar la lógica mínima del sistema en software.

Incluye:
- propuesta inicial del proyecto
- simulador base en Python
- reglas simples de detección
- alertas iniciales
- dashboard básico

## Fase 2, definición operativa
Objetivo: refinar el modelo del problema con más información del proceso real.

Pendiente de definir con nueva información:
- ciclos reales
- tipos de anomalía
- condiciones normales
- reglas de alerta
- prioridad de eventos

## Fase 3, simulador v2
Objetivo: mejorar el realismo del prototipo software.

Debería incluir:
- estados operativos mejor definidos
- anomalías graduadas
- mejor separación por ciclos
- histórico de eventos
- trazabilidad de alertas

## Fase 4, integración física
Objetivo: conectar la lógica validada con sensores reales.

Posibles señales:
- presión
- nivel
- flujo
- fuga externa
- vibración

## Fase 5, monitoreo visual
Objetivo: incorporar cámaras como capa complementaria, no como única fuente de decisión.

## Fase 6, predicción
Objetivo: pasar de detección a anticipación usando históricos y patrones.
